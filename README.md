# Ala Eddine Chatbot

Ce projet est un chatbot local développé avec Streamlit et LangChain.

## Fonctionnalités
- Interface utilisateur conviviale.
- Utilisation de modèles de langage Ollama.
- Gestion des sessions de chat.
